# 📚 Nuestros Libros / Our Books

A bilingual (Spanish / English) 3D book landing page for authors **Vanina Vergara** and **Pablo Mera** — ready to publish on GitHub Pages.

---

## ✨ Features

- **5 pages** — Welcome + 4 book pages
- **True 3D tilt** on mouse move (all interactive elements)
- **Sparking neon link effects** on hover
- **Gentle float animation** on display buttons
- **Alternating bilingual text** (Spanish / English) on all navigation buttons
- **Scrolling flags** — ES 🇪🇸 PY 🇵🇾 AR 🇦🇷 UY 🇺🇾 for Spanish books; US 🇺🇸 GB 🇬🇧 AU 🇦🇺 for English books
- **Black background · White text · Neon cyan & magenta accents**
- **Mobile responsive** — stacks cleanly on phones

## 🚀 Deploy to GitHub Pages

1. **Fork or create a new repository** on GitHub
2. Upload `index.html` to the root of the repository
3. Go to **Settings → Pages**
4. Under *Source*, select **Deploy from a branch** → `main` → `/ (root)`
5. Click **Save**
6. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

## 🎨 Design

- **Fonts:** Rajdhani (headings) + Exo 2 (body) via Google Fonts
- **Color palette:** Black `#000` · White · Cyan `#00f5ff` · Magenta `#ff00aa` · Gold `#ffd700`
- **Effects:** CSS 3D transforms, neon glow shadows, shimmer animation, particle sparks via JS
- **No dependencies** — pure HTML/CSS/JS, no frameworks
