## 🚀 Deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `libros-vergara-mera`)
2. Upload **all files** from this folder to the repository root
3. Go to **Settings → Pages**
4. Set **Source** to `Deploy from a branch` → branch `main` → folder `/ (root)`
5. Click **Save**
6. Your site will be live at `https://<your-username>.github.io/libros-vergara-mera/`

## ✨ Features

- **5 pages** in a single HTML file — no server needed
- **True 3D tilt** on hover (mouse-tracking perspective transform)
- **Gentle float animation** on all buttons
- **Alternating text & images** in buttons (auto-cycling every ~2s)
- **Sparking neon effects** on clickable links
- **Scrolling flags** 🇪🇸🇵🇾🇦🇷🇺🇾 / 🇺🇸🇬🇧🇦🇺
- **Black background, white text, neon cyan/gold accents**
- **Mobile responsive** — stacks vertically on phones
- **Zero dependencies** — pure HTML + CSS + JS
